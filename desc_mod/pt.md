> **ATT2 Project**
>
> Mod Fabric de cliente para *Across The Time II — Time For Regrets*. Adiciona interfaces e informações no jogo relacionadas aos sistemas do mapa.

## HUD

O HUD pode exibir atributos do personagem, progresso, recursos e estado do equipamento. Nas telas de configuração, é possível mostrar ou ocultar os elementos disponíveis e mudar sua posição.

## Diário de missões

O livro reúne missões principais, secundárias e diárias. É possível navegar pelas entradas, filtrá-las ou pesquisá-las, consultar objetivos e ativar o acompanhamento de uma missão.

## Magias e personagem

- Barra de magias com indicadores de recarga.
- Seletor radial para escolher o nível de algumas magias a partir do grimório.
- Telas para consultar e aprimorar os atributos do personagem.
- Menu dedicado ao reparo de equipamentos.

## Outras interfaces

O mod abre telas próprias para algumas interações do mapa, como lojas e minijogos. Também inclui uma transição visual ao se teleportar, feixes para localizar itens no chão e atalhos contextuais.

## Recursos de grupo

Com a API Party Sync conectada, itens compartilhados e marcações podem ser enviados entre jogadores do mesmo grupo. Esses recursos dependem da conexão com a API. O mod também pode exibir a presença do Discord, incluindo a atividade no jogo e a missão acompanhada.

## Compatibilidade

- Minecraft Java **1.21.11**
- Fabric Loader e Fabric API
- Java **21**
- Mod de cliente: cada jogador precisa instalá-lo; não é necessário no servidor Minecraft

## Instalação

### Launcher oficial do Minecraft

1. As versões recentes do launcher do Minecraft geralmente já incluem Java. Para uma instalação própria, instale o [Eclipse Temurin 21](https://adoptium.net/temurin/releases/?version=21).
2. Baixe e abra o [instalador oficial do Fabric](https://fabricmc.net/use/installer/). Escolha **Client** e depois **Minecraft 1.21.11**. Mantenha a versão do Fabric Loader sugerida pelo instalador.
3. Inicie o jogo uma vez usando o perfil Fabric e feche-o.
4. Baixe o [Fabric API 0.141.6 para Minecraft 1.21.11](https://modrinth.com/mod/fabric-api/version/6qAuTtLR) e o ATT2 Project na lista de versões abaixo.
5. Coloque os dois arquivos `.jar` na pasta `mods` do jogo. No launcher, abra a pasta em **Instalações → perfil Fabric → abrir pasta do jogo**. Crie `mods` caso não exista.
6. Inicie o Minecraft usando o perfil Fabric **1.21.11**.
