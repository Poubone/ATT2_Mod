> **ATT2 Project**
>
> *Across The Time II — Time For Regrets* के लिए Fabric क्लाइंट मॉड। यह मैप के सिस्टम से जुड़ी इन-गेम स्क्रीन और जानकारी जोड़ता है।

## HUD

HUD में पात्र के आँकड़े, प्रगति, संसाधन और उपकरणों की स्थिति दिखाई जा सकती है। सेटिंग स्क्रीन से उपलब्ध चीज़ों को दिखाएँ, छिपाएँ और उनकी जगह बदलें।

## क्वेस्ट जर्नल

क्वेस्ट बुक में मुख्य, साइड और दैनिक क्वेस्ट शामिल हैं। क्वेस्ट देखें, फ़िल्टर करें या खोजें; उनका उद्देश्य पढ़ें और ट्रैकिंग चालू करें।

## मंत्र और पात्र

- कूलडाउन संकेतों वाली मंत्र पट्टी।
- कुछ मंत्रों का स्तर चुनने के लिए रेडियल मेनू।
- पात्र के आँकड़े देखने और अपग्रेड करने की स्क्रीन।
- उपकरण मरम्मत के लिए अलग मेनू।

## अन्य इंटरफ़ेस

दुकानों और मिनीगेम जैसी मैप की कुछ गतिविधियों के लिए मॉड अलग स्क्रीन दिखाता है। इसमें टेलीपोर्ट के समय दृश्य संक्रमण, ज़मीन पर गिरी वस्तुओं को खोजने के लिए प्रकाश किरणें और संदर्भ के अनुसार शॉर्टकट भी शामिल हैं।

## समूह सुविधाएँ

Party Sync API से जुड़ने पर एक ही समूह के खिलाड़ियों के बीच साझा की गई वस्तुएँ और पिंग भेजे जा सकते हैं। इन सुविधाओं के लिए API कनेक्शन आवश्यक है। मॉड Discord Rich Presence में गेम गतिविधि और ट्रैक की जा रही क्वेस्ट भी दिखा सकता है।

## संगतता

- Minecraft Java **1.21.11**
- Fabric Loader और Fabric API
- Java **21**
- क्लाइंट मॉड: हर खिलाड़ी को इसे इंस्टॉल करना होगा; Minecraft सर्वर पर इसकी ज़रूरत नहीं है।

## इंस्टॉलेशन

### आधिकारिक Minecraft Launcher

1. नए Minecraft Launcher में आमतौर पर Java शामिल होता है। अलग Java इंस्टॉलेशन के लिए [Eclipse Temurin 21](https://adoptium.net/temurin/releases/?version=21) इंस्टॉल करें।
2. [आधिकारिक Fabric Installer](https://fabricmc.net/use/installer/) डाउनलोड करके खोलें। **Client**, फिर **Minecraft 1.21.11** चुनें। Fabric Loader का सुझाया हुआ संस्करण रहने दें।
3. Fabric प्रोफ़ाइल से गेम एक बार चलाएँ, फिर बंद करें।
4. [Minecraft 1.21.11 के लिए Fabric API 0.141.6](https://modrinth.com/mod/fabric-api/version/6qAuTtLR) और नीचे की संस्करण सूची से ATT2 Project डाउनलोड करें।
5. दोनों `.jar` फ़ाइलें गेम के `mods` फ़ोल्डर में रखें। Launcher में **Installations → Fabric profile → Open Game Folder** से फ़ोल्डर खोलें। `mods` न हो तो बना लें।
6. **1.21.11** Fabric प्रोफ़ाइल से Minecraft चलाएँ।
