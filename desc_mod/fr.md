> **ATT2 Project**
>
> Mod client Fabric pour *Across The Time II — Time For Regrets*. Il ajoute plusieurs interfaces et informations en jeu autour des systèmes de la carte.

## HUD

Le HUD peut afficher les statistiques du personnage, la progression, les ressources et l’état de l’équipement. Les éléments disponibles peuvent être activés, masqués et repositionnés depuis les menus de configuration.

## Journal de quêtes

Le grimoire regroupe les quêtes principales, secondaires et quotidiennes. Il permet de parcourir les entrées, de les filtrer ou de les rechercher, puis d’afficher l’objectif d’une quête et d’en activer le suivi.

## Sorts et personnage

- Barre de sorts avec indicateurs de recharge.
- Sélecteur radial pour choisir le niveau de certains sorts depuis leur grimoire.
- Interfaces de statistiques et d’amélioration du personnage.
- Menu dédié à la réparation de l’équipement.

## Autres interfaces

Le mod remplace certaines interactions de la carte par des écrans dédiés, notamment pour des boutiques et mini-jeux. Il ajoute aussi une transition visuelle lors des téléportations, des faisceaux pour repérer les objets au sol et plusieurs raccourcis contextuels.

## Fonctions de groupe

L’API Party Sync peut relayer les objets partagés et les pings entre joueurs présents dans le même groupe. Ces fonctions nécessitent une connexion à l’API. Le mod peut également afficher une présence Discord, avec l’activité en jeu et la quête suivie.

## Compatibilité

- Minecraft Java **1.21.11**
- Fabric Loader et Fabric API
- Java **21**
- Mod client : installation requise pour chaque joueur, pas sur le serveur Minecraft

## Installation

### Launcher Minecraft officiel

1. Le launcher Minecraft récent fournit généralement Java. Pour une installation personnalisée, installez [Eclipse Temurin 21](https://adoptium.net/temurin/releases/?version=21).
2. Téléchargez le [Fabric Installer officiel](https://fabricmc.net/use/installer/), ouvrez-le et choisissez **Client**, puis **Minecraft 1.21.11**. Laissez la version de Fabric Loader proposée par l’installateur.
3. Ouvrez le profil Fabric une fois, puis fermez le jeu.
4. Téléchargez [Fabric API 0.141.6 pour Minecraft 1.21.11](https://modrinth.com/mod/fabric-api/version/6qAuTtLR) et le fichier ATT2 Project depuis la liste des versions ci-dessous.
5. Placez les deux fichiers `.jar` dans le dossier `mods` du jeu. Dans le launcher, ouvrez le dossier depuis **Installations → profil Fabric → ouvrir le dossier du jeu**. Créez `mods` s’il n’existe pas.
6. Lancez Minecraft avec le profil Fabric en **1.21.11**.
