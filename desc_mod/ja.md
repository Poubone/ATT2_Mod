> **ATT2 Project**
>
> *Across The Time II — Time For Regrets*向けの Fabric クライアント Mod です。マップの各種システムに関連する画面や情報をゲーム内に追加します。

## HUD

キャラクターのステータス、進行状況、リソース、装備の状態を HUD に表示できます。設定画面から表示項目を切り替えたり、配置を変更したりできます。

## クエストジャーナル

クエストブックではメイン、サブ、デイリークエストを確認できます。項目の閲覧、検索、フィルターに加え、目標の確認や追跡の設定ができます。

## 魔法とキャラクター

- クールダウン表示付きの魔法バー。
- グリモワールから一部の魔法レベルを選べるラジアルメニュー。
- キャラクターのステータス確認・強化画面。
- 装備修理専用メニュー。

## その他の画面

ショップやミニゲームなど、マップ内の一部の操作を専用画面で表示します。また、テレポート時の演出、ドロップアイテムを見つけるための光柱、状況に応じたショートカットを追加します。

## グループ機能

Party Sync API に接続すると、同じグループにいるプレイヤー間でアイテム共有やピンを中継できます。利用には API への接続設定が必要です。Discord のプレゼンスにはゲーム内の状況や追跡中のクエストも表示できます。

## 動作環境

- Minecraft Java **1.21.11**
- Fabric Loader、Fabric API
- Java **21**
- クライアント Mod：各プレイヤーの環境に導入します。Minecraft サーバーへの導入は不要です。

## インストール

### Minecraft 公式ランチャー

1. 最近の Minecraft ランチャーには通常 Java が含まれています。独自の Java を使う場合は [Eclipse Temurin 21](https://adoptium.net/temurin/releases/?version=21) をインストールします。
2. [Fabric 公式インストーラー](https://fabricmc.net/use/installer/)をダウンロードして起動し、**Client**、**Minecraft 1.21.11** の順に選択します。Fabric Loader はインストーラーの推奨バージョンを使用してください。
3. Fabric プロファイルで一度起動し、ゲームを終了します。
4. [Minecraft 1.21.11 用 Fabric API 0.141.6](https://modrinth.com/mod/fabric-api/version/6qAuTtLR)と、下のバージョン一覧にある ATT2 Project をダウンロードします。
5. 2 つの `.jar` ファイルをゲームの `mods` フォルダーに入れます。ランチャーの **起動構成 → Fabric プロファイル → ゲームフォルダーを開く** から場所を確認できます。`mods` がなければ作成してください。
6. **1.21.11** の Fabric プロファイルで Minecraft を起動します。
