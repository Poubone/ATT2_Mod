> **ATT2 Project**
>
> A client-side Fabric mod for *Across The Time II — Time For Regrets*. It adds several interfaces and in-game information for the map’s systems.

## HUD

The HUD can show character stats, progression, resources and equipment status. Available elements can be enabled, hidden and repositioned in the configuration screens.

## Quest journal

The quest book brings together main, side and daily quests. Browse entries, filter or search them, view a quest objective and enable tracking.

## Spells and character

- Spell bar with cooldown indicators.
- Radial selector for choosing the level of certain spells from their grimoire.
- Character stats and upgrade screens.
- Dedicated equipment repair menu.

## Other interfaces

The mod replaces some map interactions with dedicated screens, including shops and mini-games. It also adds a visual teleport transition, beams to locate dropped items, and several contextual shortcuts.

## Party features

The Party Sync API can relay shared items and pings between players in the same group. These features require an API connection. The mod can also show Discord Rich Presence, including in-game activity and the tracked quest.

## Compatibility

- Minecraft Java **1.21.11**
- Fabric Loader and Fabric API
- Java **21**
- Client-side mod: each player installs it; it does not go on the Minecraft server

## Installation

### Official Minecraft Launcher

1. Recent Minecraft Launcher versions usually include Java. For a custom installation, install [Eclipse Temurin 21](https://adoptium.net/temurin/releases/?version=21).
2. Download the [official Fabric Installer](https://fabricmc.net/use/installer/), open it, choose **Client**, then **Minecraft 1.21.11**. Leave the Fabric Loader version suggested by the installer.
3. Launch the Fabric profile once, then close the game.
4. Download [Fabric API 0.141.6 for Minecraft 1.21.11](https://modrinth.com/mod/fabric-api/version/6qAuTtLR) and ATT2 Project from the version list below.
5. Put both `.jar` files in the game’s `mods` folder. In the launcher, open the folder via **Installations → Fabric profile → Open Game Folder**. Create `mods` if it does not exist.
6. Launch Minecraft with the Fabric **1.21.11** profile.
