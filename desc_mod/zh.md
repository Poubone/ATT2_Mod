> **ATT2 Project**
>
> 适用于 *Across The Time II — Time For Regrets*的 Fabric 客户端模组，为地图系统添加游戏内界面和信息。

## HUD

HUD 可显示角色属性、进度、资源和装备状态。可在设置界面中启用、隐藏并重新摆放各项内容。

## 任务日志

任务手册汇集主线、支线和每日任务。玩家可以浏览、筛选或搜索任务，查看目标并开启追踪。

## 法术与角色

- 带有冷却指示的法术栏。
- 可从法术手册中使用的环形菜单选择部分法术的等级。
- 角色属性与属性升级界面。
- 专用装备修理菜单。

## 其他界面

模组为地图中的部分交互提供专用界面，包括商店和小游戏。还加入传送过场动画、用于定位掉落物品的光柱，以及一些情境快捷键。

## 组队功能

连接 Party Sync API 后，可在同一队伍的玩家之间转发物品分享和标记。这些功能需要连接 API。模组也可显示 Discord 状态，包括游戏活动和正在追踪的任务。

## 兼容性

- Minecraft Java **1.21.11**
- Fabric Loader 和 Fabric API
- Java **21**
- 客户端模组：每位玩家都需安装，无需安装在 Minecraft 服务器上

## 安装

### Minecraft 官方启动器

1. 较新的 Minecraft 启动器通常自带 Java。若使用自定义 Java，请安装 [Eclipse Temurin 21](https://adoptium.net/temurin/releases/?version=21)。
2. 下载并打开[官方 Fabric 安装器](https://fabricmc.net/use/installer/)，选择 **Client**，再选择 **Minecraft 1.21.11**。Fabric Loader 保持安装器推荐的版本即可。
3. 使用 Fabric 配置启动一次游戏，然后关闭游戏。
4. 下载 [Minecraft 1.21.11 对应的 Fabric API 0.141.6](https://modrinth.com/mod/fabric-api/version/6qAuTtLR)，以及下方版本列表中的 ATT2 Project。
5. 将两个 `.jar` 文件放入游戏的 `mods` 文件夹。在启动器中打开 **安装 → Fabric 配置 → 打开游戏目录**。如果没有 `mods` 文件夹，请自行创建。
6. 使用 **1.21.11** 的 Fabric 配置启动 Minecraft。
