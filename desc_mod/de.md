> **ATT2 Project**
>
> Eine Fabric-Client-Mod für *Across The Time II — Time For Regrets*. Sie ergänzt Spieloberflächen und Informationen zu den Systemen der Karte.

## HUD

Das HUD kann Charakterwerte, Fortschritt, Ressourcen und den Zustand der Ausrüstung anzeigen. Die verfügbaren Elemente lassen sich in den Einstellungen ein- und ausblenden sowie neu positionieren.

## Questbuch

Das Questbuch enthält Haupt-, Neben- und tägliche Quests. Einträge lassen sich durchsuchen und filtern; außerdem können Questziele angezeigt und Quests verfolgt werden.

## Zauber und Charakter

- Zauberleiste mit Abklingzeitanzeigen.
- Radialmenü zur Auswahl der Stufe bestimmter Zauber aus ihrem Grimoire.
- Ansichten für Charakterwerte und Verbesserungen.
- Eigenes Menü zum Reparieren der Ausrüstung.

## Weitere Oberflächen

Für einige Karteninteraktionen, darunter Läden und Minispiele, öffnet die Mod eigene Ansichten. Außerdem gibt es einen visuellen Übergang beim Teleportieren, Leuchtstrahlen zum Finden fallengelassener Gegenstände und kontextbezogene Tastenkürzel.

## Gruppenfunktionen

Mit einer Verbindung zur Party-Sync-API lassen sich geteilte Gegenstände und Markierungen zwischen Spielern derselben Gruppe weiterleiten. Diese Funktionen benötigen eine API-Verbindung. Die Mod kann auch Discord Rich Presence mit Spielaktivität und verfolgter Quest anzeigen.

## Kompatibilität

- Minecraft Java **1.21.11**
- Fabric Loader und Fabric API
- Java **21**
- Client-Mod: Jeder Spieler installiert sie selbst; auf dem Minecraft-Server wird sie nicht benötigt.

## Installation

### Offizieller Minecraft Launcher

1. Neuere Minecraft-Launcher enthalten Java in der Regel bereits. Für eine eigene Java-Installation eignet sich [Eclipse Temurin 21](https://adoptium.net/temurin/releases/?version=21).
2. Lade den [offiziellen Fabric Installer](https://fabricmc.net/use/installer/) herunter und öffne ihn. Wähle **Client** und anschließend **Minecraft 1.21.11**. Übernimm die vom Installer vorgeschlagene Fabric-Loader-Version.
3. Starte das Spiel einmal mit dem Fabric-Profil und schließe es danach.
4. Lade [Fabric API 0.141.6 für Minecraft 1.21.11](https://modrinth.com/mod/fabric-api/version/6qAuTtLR) und ATT2 Project aus der Versionsliste unten herunter.
5. Lege beide `.jar`-Dateien in den `mods`-Ordner des Spiels. Im Launcher findest du ihn unter **Installationen → Fabric-Profil → Spielordner öffnen**. Falls `mods` fehlt, erstelle den Ordner.
6. Starte Minecraft mit dem Fabric-Profil für **1.21.11**.
