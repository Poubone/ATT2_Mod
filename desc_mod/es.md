> **ATT2 Project**
>
> Mod Fabric de cliente para *Across The Time II — Time For Regrets*. Añade interfaces e información dentro del juego relacionadas con los sistemas del mapa.

## HUD

El HUD puede mostrar las estadísticas del personaje, el progreso, los recursos y el estado del equipo. Desde los menús de configuración se pueden activar u ocultar los elementos disponibles y cambiar su posición.

## Diario de misiones

El libro reúne las misiones principales, secundarias y diarias. Permite consultar, filtrar y buscar entradas, ver el objetivo de una misión y activar su seguimiento.

## Hechizos y personaje

- Barra de hechizos con indicadores de recarga.
- Selector radial para elegir el nivel de ciertos hechizos desde su grimorio.
- Interfaces para consultar y mejorar las estadísticas del personaje.
- Menú específico para reparar el equipo.

## Otras interfaces

El mod muestra algunas interacciones del mapa en pantallas específicas, como tiendas y minijuegos. También añade una transición visual al teletransportarse, haces de luz para localizar objetos en el suelo y varios atajos contextuales.

## Funciones de grupo

Al conectarse a la API Party Sync, se pueden compartir objetos y enviar señales entre jugadores del mismo grupo. Estas funciones requieren conexión a la API. El mod también puede mostrar la presencia de Discord, incluida la actividad en el juego y la misión seguida.

## Compatibilidad

- Minecraft Java **1.21.11**
- Fabric Loader y Fabric API
- Java **21**
- Mod de cliente: cada jugador lo instala; no hace falta instalarlo en el servidor de Minecraft

## Instalación

### Launcher oficial de Minecraft

1. Las versiones recientes del launcher de Minecraft suelen incluir Java. Para una instalación personalizada, instala [Eclipse Temurin 21](https://adoptium.net/temurin/releases/?version=21).
2. Descarga y abre el [instalador oficial de Fabric](https://fabricmc.net/use/installer/). Elige **Client** y después **Minecraft 1.21.11**. Deja la versión de Fabric Loader que recomienda el instalador.
3. Inicia el juego una vez con el perfil Fabric y ciérralo.
4. Descarga [Fabric API 0.141.6 para Minecraft 1.21.11](https://modrinth.com/mod/fabric-api/version/6qAuTtLR) y ATT2 Project desde la lista de versiones de abajo.
5. Copia ambos archivos `.jar` en la carpeta `mods` del juego. En el launcher, abre la carpeta desde **Instalaciones → perfil Fabric → Abrir carpeta del juego**. Créala si no existe.
6. Inicia Minecraft con el perfil Fabric **1.21.11**.
