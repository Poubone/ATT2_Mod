> **ATT2 Project**
>
> Клиентский мод Fabric для *Across The Time II — Time For Regrets*. Он добавляет игровые интерфейсы и сведения, связанные с системами карты.

## HUD

HUD может показывать характеристики персонажа, прогресс, ресурсы и состояние снаряжения. В настройках можно включать и скрывать доступные элементы, а также менять их расположение.

## Журнал заданий

В книге собраны основные, побочные и ежедневные задания. Их можно просматривать, фильтровать и искать, а также смотреть цели и включать отслеживание.

## Заклинания и персонаж

- Панель заклинаний с индикаторами перезарядки.
- Круговое меню для выбора уровня некоторых заклинаний из их гримуара.
- Экраны характеристик и улучшения персонажа.
- Отдельное меню ремонта снаряжения.

## Другие интерфейсы

Для некоторых взаимодействий на карте, включая магазины и мини-игры, мод открывает отдельные экраны. Также добавлены визуальный переход при телепортации, лучи для поиска выпавших предметов и контекстные сочетания клавиш.

## Групповые функции

При подключении к API Party Sync мод может передавать общие предметы и метки между игроками одной группы. Для этих функций требуется доступ к API. Также можно включить статус Discord с игровой активностью и отслеживаемым заданием.

## Совместимость

- Minecraft Java **1.21.11**
- Fabric Loader и Fabric API
- Java **21**
- Клиентский мод: его устанавливает каждый игрок; на сервер Minecraft он не нужен

## Установка

### Официальный лаунчер Minecraft

1. В новых версиях лаунчера Minecraft обычно уже есть Java. Для собственной установки используйте [Eclipse Temurin 21](https://adoptium.net/temurin/releases/?version=21).
2. Скачайте и запустите [официальный установщик Fabric](https://fabricmc.net/use/installer/), выберите **Client**, затем **Minecraft 1.21.11**. Оставьте предложенную установщиком версию Fabric Loader.
3. Один раз запустите игру с профилем Fabric, затем закройте её.
4. Скачайте [Fabric API 0.141.6 для Minecraft 1.21.11](https://modrinth.com/mod/fabric-api/version/6qAuTtLR) и ATT2 Project из списка версий ниже.
5. Поместите оба файла `.jar` в папку `mods` игры. В лаунчере откройте папку через **Установки → профиль Fabric → Открыть папку игры**. Если папки `mods` нет, создайте её.
6. Запустите Minecraft с профилем Fabric **1.21.11**.
