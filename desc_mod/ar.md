> **ATT2 Project**
>
> إضافة Fabric من جهة العميل مخصّصة للعبة *Across The Time II — Time For Regrets*. تضيف واجهات ومعلومات داخل اللعبة مرتبطة بأنظمة الخريطة.

## واجهة HUD

يمكن للواجهة عرض إحصاءات الشخصية والتقدّم والموارد وحالة المعدات. يمكن إظهار العناصر المتاحة أو إخفاؤها وتغيير مواضعها من شاشات الإعدادات.

## سجل المهام

يجمع كتاب المهام المهام الرئيسية والجانبية واليومية. يمكنك تصفّحها وتصفيتها والبحث فيها، وعرض هدف المهمة وتفعيل تتبّعها.

## التعويذات والشخصية

- شريط تعويذات يعرض مؤشرات وقت إعادة الاستخدام.
- قائمة شعاعية لاختيار مستوى بعض التعويذات من كتابها.
- شاشات لعرض إحصاءات الشخصية وتحسينها.
- قائمة مخصّصة لإصلاح المعدات.

## واجهات أخرى

يعرض التعديل بعض تفاعلات الخريطة في شاشات مخصّصة، مثل المتاجر والألعاب المصغّرة. كما يضيف انتقالًا مرئيًا عند الانتقال الآني، وأشعة لتحديد الأغراض الساقطة، واختصارات سياقية.

## ميزات المجموعة

عند الاتصال بواجهة Party Sync API، يمكن إرسال الأغراض المشتركة والتنبيهات بين اللاعبين في المجموعة نفسها. تتطلب هذه الميزات الاتصال بالواجهة. ويمكن أيضًا عرض حالة Discord، بما فيها النشاط داخل اللعبة والمهمة المتتبّعة.

## التوافق

- Minecraft Java **1.21.11**
- Fabric Loader وFabric API
- Java **21**
- تعديل للعميل: يثبّته كل لاعب، ولا حاجة إلى تثبيته على خادم Minecraft

## التثبيت

### مشغّل Minecraft الرسمي

1. تتضمن إصدارات مشغّل Minecraft الحديثة Java عادةً. إذا كنت تستخدم تثبيتًا مخصّصًا، فثبّت [Eclipse Temurin 21](https://adoptium.net/temurin/releases/?version=21).
2. نزّل [مثبّت Fabric الرسمي](https://fabricmc.net/use/installer/) وافتحه، ثم اختر **Client** وبعدها **Minecraft 1.21.11**. اترك إصدار Fabric Loader الذي يقترحه المثبّت.
3. شغّل اللعبة مرة واحدة باستخدام ملف تعريف Fabric، ثم أغلقها.
4. نزّل [Fabric API 0.141.6 الخاص بـ Minecraft 1.21.11](https://modrinth.com/mod/fabric-api/version/6qAuTtLR) وملف ATT2 Project من قائمة الإصدارات أدناه.
5. ضع ملفي `.jar` في مجلد `mods` الخاص باللعبة. من المشغّل افتح المجلد عبر **Installations → ملف Fabric → Open Game Folder**. أنشئ مجلد `mods` إذا لم يكن موجودًا.
6. شغّل Minecraft باستخدام ملف Fabric التعريفي **1.21.11**.
